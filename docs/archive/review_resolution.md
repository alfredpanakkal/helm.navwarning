# Review Findings Resolution Matrix (v7 to v8)

All findings from the safety and architectural review of `implementation_plan_v7.md` have been systematically resolved as documented below.

| Finding ID | Severity | Target Section in v7 / v8 | Defect Description | Resolution Status & Section Reference |
| :--- | :--- | :--- | :--- | :--- |
| **F01** | **S1** | Section 6 (Public Visibility) | Hiding Tier C records contradicted invariant I5 by suppressing active warnings whose positions failed to parse. | **RESOLVED (Section 6)**: Added complete Visibility Matrix. Public portal displays raw text with warning banner ("position not verified, see original text") and NO map plot. Only non-mariner records (empty stubs, meta lists, cancelled archives) are hidden. |
| **F02** | **S2** | Sections 10, 11, 12 | Register rules for unrepresented NAVAREAs added regex risk without corpus fixtures. | **RESOLVED (Section 10 & `rule_applicability.csv`)**: Added `rule_applicability` matrix. Rules are classified as `implement_now` or `defer_dormant` based on corpus evidence. |
| **F03** | **S2** | Section 5 (Tier Assignment) | "Outside coordinate tokens" is unknowable prior to lexing/parsing. | **RESOLVED (Section 5)**: Implemented post-extraction `assignTier()` function checking span overlap with sensitive tokens (coordinates, quantities, IDs, dates). |
| **F04** | **S1** | Section 5 & Section 10 | Rules 3, 108, 114 alter canonical warning ID/year; Rules 115, 122 assign chart/vessel constraints. | **RESOLVED (Section 5 & 10)**: Introduced `IDENTITY_AFFECTING` flag (Rules 3, 108, 114) forcing Tier B triage and side-by-side raw/derived header display in admin. Rules 115 and 122 mapped to Tier B. |
| **F05** | **S1** | Section 4.2 & Section 9 | Lifecycle flaws: effectiveAt vs issuedAt mismatch; unhandled silent reinstatement; inferred cancellation risks. | **RESOLVED (Section 4.2)**: Provided formal `resolve()` pseudo-code algorithm, `LifecycleResult` interface, and 8 test vectors (L1–L8). Inferred cancellations set `proposed_cancel` without auto-hiding. |
| **F06** | **S2** | Section 7 (Persistence) | Missing publish gate link to `ingestion_generations`; single `data_quality` column failed to capture per-group quality. | **RESOLVED (Section 7)**: Linked publish gate to generations; added per-group JSON quality (`groups[].quality`), message-level worst-of rollup, and `parser_version`/`rules_version` columns. |
| **F07** | **S2** | Section 10 (Rule 116) | Regex order matched `OM` before `OMAN`; bare `F` prefix matched prose words like "ZONE F". | **RESOLVED (Section 10)**: Ordered chart prefixes longest-first (`OMAN\|OM`). Restricted bare `F`/`H-` prefixes to `CHARTS` clause context followed by digits (`\bF\s?\d{2,4}\b`). |
| **F08** | **S3** | Section 9 (Pipeline) | Rule 66 (multi-envelope reassembly) was missing from Phase 1 pre-splitter rules. | **RESOLVED (Section 9)**: Added Rule 66 explicitly to Phase 1 sanitization before message splitting (Rule 106). |
| **F09** | **S3** | Section 12 (Milestones) | Milestone M1 was over-scoped. | **RESOLVED (Section 12)**: Split M1 into M1a (safety foundation, publish gate, migration, public filtering) and M1b (visual states, badges, queue UI). M1b can ship post-M2. |
| **F10** | **S1** | Section 4 (Hemisphere) | Warnings stating "ALL POSITIONS ARE NORTH AND EAST" had no scoped representation. | **RESOLVED (Section 4.6)**: Added `hemisphereConvention` (`{phrase, rawSpan, scope: warningId}`), flag `HEMISPHERE_CONVENTION_APPLIED`, Tier B routing, and vectors H1/H2. |
| **N01** | **S2** | Sections 3 & 6 | Mismatch between `status: 'superseded'` and `proposed_cancel` interaction. | **RESOLVED (Section 3 & 4.2)**: Defined formal `LifecycleResult` type. `status` changes strictly on explicit cancellation criteria or operator approval. |
| **N02** | **S1** | Section 9 (AI Escalation) | Risk of AI coordinate hallucination and prompt injection. | **RESOLVED (Section 9.1)**: Added mandatory numeric token grounding check against raw text, prompt quarantine instruction, Tier C routing on grounding failure, and vectors AI1/AI2. |
| **N03** | **S1** | Section 9.2 (Regex Safety) | Catastrophic ReDoS backtracking risk on server inputs. | **RESOLVED (Section 9.2)**: Added per-regex complexity audit, input size caps, per-message execution timeouts, parse_failure recording on timeout, and adversarial test suite RX1. |
| **N04** | **S2** | Section 9.3 (Offset Map) | Offset map correctness lacked mathematical invariants. | **RESOLVED (Section 9.3)**: Added 4 formal invariant tests: round-trip reconstruction, span mapping integrity, property/fuzz testing, and idempotency (`sanitize(sanitize(x)) == sanitize(x)`). |
| **N05** | **S2** | Section 9 (Pipeline Order) | Pipeline list lacked strict dependency DAG ordering. | **RESOLVED (Section 9)**: Defined explicit 11-phase rule DAG (`phase_1_sanitize` through `phase_11_publish_gate`). Verified no rule consumes output of a later rule. |
| **N06** | **S1** | Section 7.2 (Queue) | Re-ingestion could overwrite human-verified geometries. | **RESOLVED (Section 7.2)**: Bound human verification to `content_hash = sha256(raw_text + canonical_geometry)`. | **N07** | **S2** | Section 4.3 (Bounding Box) | Bounding box min/max failed on antimeridian wrap (>180° span). | **RESOLVED (Section 4.3)**: Added antimeridian wrap detection, scalar ordering, missing hemisphere quarantine (Tier C), and test vectors BB1, BB2, BB3. |
| **N08** | **S2** | Section 4.7 (Rule 111) | Spelled-number conversion lacked unit conversion constants. | **RESOLVED (Section 4.7)**: Added unit constants table (1 NM = 1852m, 1 cable = 185.2m, 1 yard = 0.9144m), unit context requirement, and flag `unit_assumed: NM`. |
| **N09** | **S2** | Section 13 (Test Strategy) | Lack of negative test vectors and true held-out corpus. | **RESOLVED (Section 13)**: Required >=1 positive and >=1 negative vector per rule. Added 4-week forward holdout strategy. |
| **N10** | **S3** | Section 3 (Naming) | Mixed `camelCase` and `snake_case` in field specifications. | **RESOLVED (Section 3 & 7)**: Standardized DB columns to `snake_case` and TypeScript properties to `camelCase` with a documented mapping layer. |
